# CRUD App (Node + Express + SQLite)

Simple single-file frontend served from an Express backend, backed by SQLite.

Database file

- `data.db` is created automatically the first time you start the server and create or seed data.
- If you want to see the file immediately, run the seed script below.

Setup

1. Install dependencies:

```bash
npm install
```

2. Start server:

```bash
npm start
```

Open http://localhost:3000 in your browser.

Optional: create sample data and generate `data.db`

```bash
npm run seed
```
